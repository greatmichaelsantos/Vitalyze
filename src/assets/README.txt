ASSET PLACEHOLDERS
==================
Place the following image files in this directory:

- icon.png             (1024×1024 — app icon, purple #6C47FF background with white pulse icon)
- splash.png           (1242×2436 — splash screen image)
- adaptive-icon.png    (1024×1024 — Android adaptive icon foreground)
- favicon.png          (48×48 — web favicon)
- notification-icon.png (96×96 — Android notification icon, white on transparent)

Until you add real images, expo will use its default placeholder assets.
You can generate these at: https://www.appicon.co/
